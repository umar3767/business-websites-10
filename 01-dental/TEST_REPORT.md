# Реальный отчёт QA — 01-dental

**Дата:** 2026-10-20. **Результат:** 64/64 успешных проверок; найденных ошибок в финальном повторном прогоне: 0.

## Фактически выполнено

- Запущен реальный `/usr/bin/chromium` через Python Playwright: `python scripts/qa_browser.py 1 1` (для отдельных пакетов выполнялись групповые запуски с диапазонами).
- Отрендерены все четыре страницы в headless Chromium с загруженными локальными CSS, JavaScript и SVG; проверены `h1`, навигационные пункты, landmarks, изображения, футер с режимом demo, отсутствие `pageerror`.
- Проверены пять размеров **320×700, 390×844, 768×1024, 1440×900, 1920×1080**, отсутствие горизонтальной прокрутки на главной, мобильное меню и навигация.
- Переключены RU → UZ → RU на всех четырёх страницах, проверено сохранение языка в browser storage (mocked localStorage для изолированного browser document).
- Активирован уникальный функционал: **service category filtering**. Проверен результат изменения пользовательского выбора.
- Сняты реальные Chromium-скриншоты главной и страницы услуг, 1440×900 и 390×844. Дополнительные снимки специфичных интерактивных страниц находятся в `screenshots/` общего пакета.
- Выполнены `node --check` для `app.js` и `content/site-data.js`, файловая проверка **четырёх HTML + 404** и относительных ассетов.

## Принципиальные ограничения проверки

Из-за административной блокировки Chromium при переходе к `file://` и `http://127.0.0.1`, автоматический browser QA использовал `page.set_content` с загрузкой локальных файлов CSS/JS/SVG в тот же настоящий движок Chromium. Код выполнялся в браузере, но **переходы по реальным URL в браузере и реальная инфраструктура хостинга НЕ были end-to-end проверены**. Относительные ссылки и существование файлов проверены статически. В браузерном документе origin `about:blank` native localStorage недоступен, поэтому для теста переключения языка использован изолированный storage shim. Работа на опубликованном домене должна быть проверена отдельно с настоящим origin.

Исходный UX-чек включает генерацию локальных SVG-иллюстраций, а не editorial photography. Лицензированные фотографии следует добавлять после получения подходящих материалов. Никакие реальные бизнес-контакты не настраивались; WhatsApp/call/live-booking не подтверждались на реальной компании. Lighthouse и axe-core **не запускались**; оценки скорости/доступности не выдуманы. Требуется ручная проверка screen reader, юридических данных и контента перед продакшеном.
